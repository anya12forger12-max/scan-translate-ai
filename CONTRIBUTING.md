# Contributing

Thank you for your interest in contributing!

## Getting started

1. Fork the repository and clone your fork.
2. Run `./install.sh` to set up dependencies.
3. Create a feature branch: `git checkout -b feat/your-change`.
4. Make your changes, adding tests where appropriate.
5. Run the test suite (see README) and ensure it passes.
6. Commit with a clear message and open a pull request.

## Code style

- Follow the existing style and linting rules.
- Keep changes focused and minimal.

## Reporting issues

Open an issue with a clear reproduction and expected vs. actual behavior.
